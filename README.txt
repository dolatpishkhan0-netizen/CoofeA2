A2 DIGITAL MENU

1) index.html = منوی مشتری
2) admin.html = پنل مدیریت
3) رمز پنل مدیریت: 8888

ویژگی‌ها:
- صفحه اصلی با تصویر پس‌زمینه آبی/بنفش نئونی A2
- مشتری در صفحه اصلی دکمه مدیریت نمی‌بیند.
- مدیر از طریق admin.html وارد پنل می‌شود.
- مدیر می‌تواند غذا/نوشیدنی را اضافه، ویرایش و حذف کند.
- برای هر محصول امکان انتخاب عکس از گوشی/کامپیوتر اضافه شده است.
- عکس محصول فشرده شده و در localStorage همان مرورگر ذخیره می‌شود.

نکته امنیتی:
این پروژه روی GitHub Pages استاتیک است. رمز در کد پنل وجود دارد و فقط از رابط منوی مشتری پنهان است؛ بنابراین برای امنیت واقعی و جلوگیری از دسترسی فنی، باید در نسخه بعدی احراز هویت و دیتابیس سمت سرور اضافه شود.

نکته ذخیره‌سازی:
تغییرات و عکس‌ها در همین مرورگر/دستگاه ذخیره می‌شوند و خودکار بین گوشی‌ها یا دستگاه‌های مختلف همگام نمی‌شوند.
